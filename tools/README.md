# Local tools

PowerShell harnesses are grouped by purpose.

## `aesthetic/`
Aesthetic Brain, A/B stability, semantic shortlist, semantic-selection, and candidate-gate diagnostics.

## `repair/`
Guarded repair experiments, keep/rollback checks, rollback regressions, and shadow decisions.

## `diagnostics/`
Focused one-off diagnostics such as microtext inspection.

## `visual/`
General local visual pipeline checks.

These tools are local/read-only unless a script explicitly documents a guarded reversible write test. Never paste WordPress Application Passwords or other credentials into source control.
